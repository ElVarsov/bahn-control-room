## Zero-Hang Dataset Fallback & Database Probe

Observed: When running locally without Docker/Postgres, queries to `DATABASE_URL` hung for 30s awaiting connection timeouts, causing client fetches to abort with "Could not load the list" on `/drivers`, `/customers`, `/sites`, and `/inbox`.
Analysis: `postgres.js` defaults to a long connect timeout when port 5432 is unreachable on Windows.
Fix:
- Added a 300ms non-blocking TCP socket check (`isDbAvailable()`) in `lib/db.ts` and set `connect_timeout: 1`.
- Built `lib/present/dataset.ts` with multi-path resolution ensuring dataset files are loaded in under 5ms.
- Connected drivers, customers, and sites to real `BoardCard` projections so opening any entity shows their active delivery orders.
