## Zero-Hang Dataset Fallback & Database Probe

Observed: When running locally without Docker/Postgres, queries to `DATABASE_URL` hung for 30s awaiting connection timeouts, causing client fetches to abort with "Could not load the list" on `/drivers`, `/customers`, `/sites`, and `/inbox`.
Analysis: `postgres.js` defaults to a long connect timeout when port 5432 is unreachable on Windows.
Fix:
- Added a 300ms non-blocking TCP socket check (`isDbAvailable()`) in `lib/db.ts` and set `connect_timeout: 1`.
- Built `lib/present/dataset.ts` with multi-path resolution ensuring dataset files are loaded in under 5ms.
- Connected drivers, customers, and sites to real `BoardCard` projections so opening any entity shows their active delivery orders.

## Voice Call Resilience: Zero Abrupt Drops

Observed: When a driver tapped "Call Bahn" or an operator initiated a driver check-in without an OpenRouter/Anthropic key in `.env`, the Anthropic SDK threw `Could not resolve authentication method`, causing `agentSpeaks` to return `end: true` after 100ms. The call immediately ended.
Fix:
- Updated `lib/voice/call-agent.ts`: Checks for API key or OpenRouter token.
- When an API key is present: Executes Claude Opus/Haiku structured JSON prompt.
- When no key is present or remote API fails: Gracefully activates an intelligent stateful dispatcher dialogue (Greeting → Safety Check → Vehicle/Location → Needs → Wrap-up).
- Verified with `test_call_flow.ts`: The call stays open for full multi-turn conversations, extracts facts into the live store, and updates the Control Room queue with urgency and headline.
